# Inteligencia Artificial | RIWI

Repositorio de actividades prácticas desarrolladas durante el módulo de **Inteligencia Artificial** de RIWI.

## Actividades

### 1. Ordenamiento en Python

Ejercicio de lógica de programación que consiste en ordenar tres números de menor a mayor utilizando variables y estructuras condicionales (`if`, `elif`, `else`).

El algoritmo contempla diferentes órdenes de entrada, incluidos números repetidos.

**Ubicación:** `01-ordenamiento-python/`

### 2. Trabajo en parejas

Actividad colaborativa desarrollada durante el módulo de Inteligencia Artificial.

**Ubicación:** `02-trabajo-parejas/`

### 3. Reto de Prompt Engineering — APEX Kombat

Desarrollo de un prototipo web de una liga de combates entre robots humanoides mediante Lovable.

El proyecto incluye una landing page, páginas de atletas y eventos, y una simulación de compra de entradas.

El repositorio independiente contiene el código generado, los prompts originales y la documentación del proceso.

**[Ver proyecto APEX en GitHub](https://github.com/Riwi-Coders/t800-arena-showdown)**
